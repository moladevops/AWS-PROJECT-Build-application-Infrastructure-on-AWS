# AWS-PROJECT-1-Build-application-Infrastructure-on-AWS
Team project: a scalable, secure multi-tier web app on AWS. VPC with public/private subnets, ELB, Auto Scaling EC2, RDS, EFS shared storage, S3 and EBS for logs and backups, Route 53 DNS, CloudWatch monitoring with SNS alerts, and IAM roles for least-privilege access. The whole infrastructure is defined as code with Terraform.
